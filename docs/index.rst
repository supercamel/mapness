Mapness
=======

Mapness is a GTK4 map widget written in Vala. It provides a small embeddable
map surface with tile loading, panning, scroll-wheel zoom, overlays, tracks,
polygons, images, and GObject introspection bindings.

The 2.0 API targets GTK4 and libsoup3. The introspection namespace is
``mapness`` version ``2.0``. The Vala and pkg-config package name is
``mapness-2.0``.
